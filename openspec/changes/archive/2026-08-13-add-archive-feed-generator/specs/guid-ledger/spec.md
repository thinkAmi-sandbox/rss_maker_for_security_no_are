# Spec Delta: guid-ledger

## ADDED Requirements

### Requirement: guid 台帳の形式

guid 台帳は、リポジトリにコミットされる CSV ファイルであり、ヘッダ行 `p,guid,first_seen` を持たなければならない(MUST)。各行は、公式フィードで観測した1記事分の記録である: `p` は記事番号(整数)、`guid` はフィードが配信した guid 文字列の**無加工の転記**(スキーム情報の保存が目的のため、正規化・書き換えをしてはならない(MUST NOT))、`first_seen` は初観測日(ISO 8601 日付)。行は p 番号の昇順で保存し、git の差分が追記行のみになるようにしなければならない(MUST)。

#### Scenario: 台帳の初回生成

- **WHEN** 台帳が存在しない状態で生成コマンドを実行する
- **THEN** 現行フィードの全 item(p 番号と guid)が p 昇順で記録された台帳が新規作成される

### Requirement: 追記のみの更新規則

台帳の更新は生成コマンドの一部として毎回実行されなければならない(MUST)。フィードに存在する p 番号のうち台帳にないものだけを追記し、既存行はいかなる場合も書き換えても削除してもならない(MUST NOT)。guid は WordPress の仕様上、投稿作成時に固定され以後不変であるため、初観測1回で確定とみなす。

#### Scenario: 新しい回の追記

- **WHEN** 前回実行後に公式フィードへ新しい回が追加された状態で実行する
- **THEN** 新しい回の (p, guid, 実行日) だけが台帳に追記され、既存行は1バイトも変わらない

#### Scenario: 冪等な再実行

- **WHEN** フィードの状態が変わらないまま生成コマンドを2回実行する
- **THEN** 2回目の実行で台帳は変更されない

### Requirement: guid 食い違いの検出

既知の p 番号に対して、フィードが台帳の記録と異なる guid 文字列を配信してきた場合、ツールは両方の値を明示したエラーで異常終了しなければならない(MUST)。これは「guid は不変」という前提の崩れ(=本ツールの重複排除契約全体の崩れ)を検出する監視機構である。この状態が発生した場合の対応は人間の判断に委ねる(公式が過去回を別 guid で再配信し始めた場合、本ツールは役目を終える、という設計判断)。

#### Scenario: guid ドリフトの検出

- **WHEN** 台帳に `p=1587, guid=http://www.tsujileaks.com/?p=1587` とある状態で、フィードが同じ p=1587 に `https://www.tsujileaks.com/?p=1587` を配信してくる
- **THEN** 台帳の値とフィードの値の両方を明示したエラーで異常終了し、台帳も archive.xml も変更されない

### Requirement: アーカイブ item の guid 決定順位

archive.xml の各 item の guid は、次の優先順位で決定しなければならない(MUST):

1. 台帳にその p 番号の記録があれば、**台帳の guid 文字列をそのまま**使う(観測済みの事実)
2. なければ `http://www.tsujileaks.com/?p=<記事番号>` を合成する(歴史的証拠に基づく推定)

http で合成する根拠: フィード最古付近の44件(p=491〜846)の guid が例外なく http であり、2017年の Wayback スナップショットでも http だったこと。台帳開始(2026-08)以前に押し出された回(p=10〜488)はこの推定に頼るしかない。合成 guid は「当時の実 guid と完全一致する保証」ではなく最善の推定であることを、利用者向け文書に明記しなければならない(MUST)。

#### Scenario: 台帳にある回の guid

- **WHEN** 将来押し出された回(台帳に観測記録あり)をアーカイブに含める
- **THEN** その item の guid は台帳に記録された文字列と完全一致する

#### Scenario: 台帳にない過去回の guid 合成

- **WHEN** 台帳開始以前に押し出されていた回(例: p=426)をアーカイブに含める
- **THEN** その item の guid は `http://www.tsujileaks.com/?p=426`(http・www あり・isPermaLink="false")になる
